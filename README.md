## One Week Sales Data Analysis

An Excel-based sales analysis project exploring weekly sales performance through charts, reports, and data insights.

## Project Overview

This project analyzes one week of sales data using Microsoft Excel to explore sales trends and business performance.

## Analysis Areas

-  Daily sales trends
-  Customer type analysis
-  Regional and city-wise sales
-  Product category performance
-  Payment method analysis
-  Order status analysis

## Tools Used

- Microsoft Excel
- Pivot tables and charts
- Data analysis and visualization

## Project Files

- `One Week Sales Data Project.xlsx` — Excel workbook containing the sales data, analysis, and charts.

## Project Objective

To explore sales data, identify patterns, and present business information through clear Excel reports and visualizations.
